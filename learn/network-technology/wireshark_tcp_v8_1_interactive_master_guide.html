Q6 เครื่องคำนวณ EstimatedRTT (RFC 6298)

α = 0.125

ในโจทย์กำหนดให้: ค่าเริ่มต้น EstimatedRTT₁ = SampleRTT₁ (ของ segment แรก) จากนั้นคำนวณรอบถัดไปด้วยสูตร EWMA (Exponential Weighted Moving Average):

EstimatedRTT = (1 - α) × EstimatedRTT + α × SampleRTT
= 0.875 × EstimatedRTT + 0.125 × SampleRTT
ค่าเริ่มต้นใน trace ≈ 0.0294 วินาที
RTT ของ segment ที่ 2 ≈ 0.0278 วินาที
ผลการคำนวณ EstimatedRTT หลังรับ ACK ของ segment ที่ 2:
0.0292 วินาที (29.20 ms)
= (0.875 × 0.0294) + (0.125 × 0.0278) = 0.025725 + 0.003475 = 0.0292 s

Q11 เครื่องคำนวณ Throughput ของ TCP Connection

Data / Time

Throughput คืออัตราการส่งข้อมูลสำเร็จต่อหน่วยเวลา คิดจาก ข้อมูลทั้งหมดที่ส่ง หารด้วย เวลาตั้งแต่เริ่มส่งชิ้นแรกจนถึงรับ ACK สุดท้าย

Throughput = Total Bytes Transferred / Total Elapsed Time (s)
ขนาด HTTP payload ทั้งหมด (~152 KB)
เวลาของ Packet #4 (HTTP POST)
เวลาของ ACK สำหรับ data packet สุดท้าย
ผลการคำนวณ Throughput:
1,517,732 Bytes/sec (~1.52 MB/s)
= 152,359 Bytes / (0.1255 - 0.025114) s = 152,359 / 0.100386 ≈ 12.14 Mbps

📌 สูตรและนิยามสำคัญที่อาจารย์ชอบออกข้อสอบ / ถามใน Lab

1. TCP Segment Length

TCP Length = IP Total Length - IP Header Length - TCP Header Length
ปกติ IP Header = 20B, TCP Header = 20-32B ถ้า IP Len = 1500, Payload จะได้ 1460 หรือ 1440 Bytes

2. Receiver Advertised Window

Actual Window = Window Size Value × Window Scaling Factor
หากใน SYN มีการแลกเปลี่ยน Window Scale เช่น ×64 หรือ ×128 ต้องนำมาคูณค่าใน Header ด้วย

3. Delayed ACK (RFC 1122)

ฝั่งรับ (Receiver) จะไม่ส่ง ACK ทันทีทุกแพ็กเก็ต แต่มักจะ ACK ทุกๆ 2 segments (ทุกๆ ~2920 bytes) หรือรอหน่วงเวลาไม่เกิน 500ms

🚀 1. ทำไมจุดถึงเรียงเป็น "เสาตั้งๆ" (Fleets)?

จุดแต่ละจุดคือ TCP segment ที่ส่งออกไป เมื่อเวลาเดียวกันส่งติดๆ กันหลายแพ็กเก็ต (burst/fleet) จะเห็นจุดเรียงซ้อนกันในแนวดิ่ง

⚡ 2. กำลังอยู่ในเฟส Slow Start หรือไม่?

ใช่ (Slow Start)! สังเกตจากจำนวนจุดในแต่ละ Fleet (ชุด) ที่เพิ่มขึ้นเป็นทวีคูณ (1 → 2 → 4 → 8... แพ็กเก็ต) ตามค่า cwnd (Congestion Window) ที่เพิ่มขึ้นในแต่ละ RTT

⏱️ 3. Periodicity (ความถี่ของรอบ) คืออะไร?

ระยะห่างเวลาระหว่างเสาแต่ละเสา (เช่น t=0.025, 0.053, 0.082) มีค่าห่างกันประมาณ ~0.028 วินาที ซึ่งเท่ากับค่า RTT (Round Trip Time) นั่นเอง! เพราะผู้ส่งต้องรอ ACK กลับมาก่อน ถึงจะปล่อย Fleet ใหม่ออกไปได้
